# Covenants — The Tale of Taming the Beast

A ten-episode vertical-scroll webtoon fable explaining Bitcoin covenants and
Kaspa's Toccata upgrade, told through a Kuniyoshi woodblock-print beast story.

- Start at the series index: [`index.html`](index.html)
- Episodes: `episode-00/` … `episode-09/` — each `reader.html` is a complete,
  self-contained vertical scroll (slices + transcript + sources).
- All artwork is baked into the episode slices; `assets/` holds only the
  eleven plates used as index cards.
